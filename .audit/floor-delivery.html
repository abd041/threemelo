ThreeMelo floor-plan upgrade

Delivery date: November 25, 2026 · Repository implementation · No deployment

Production ready with documented limitations

A. Executive summary

The original compact rectangular-room editor has become a browser-local floor-planning studio with typed project geometry, polygon rooms, shared walls with real openings, direct manipulation, imperial and metric inputs, history, procedural furniture/materials, twelve templates, multiple saved projects and five export formats. The existing Next.js architecture, Three.js dependency, URL and purple ThreeMelo identity are preserved. Changes outside the floor-planner scope are limited to reciprocal links, the central registry, compatible TypeScript tooling and tests that recognize the modular source layout.

The original 258 tests remain passing. The final suite has 304 passing tests, including 46 added floor-planner tests. This is a substantial implemented upgrade, not a claim that every advanced requirement reached a 10/10 standard. The matrix below records unfinished and partially supported features.

G. Known limitations

  • One story per project; no ceiling/roof system, per-vertex polygon editor or full architectural wall miter solver.
  • Area uses centerline polygons, not a certified net usable-area standard. Drawings are conceptual and do not validate structural safety, building codes, ergonomics or professional standards.
  • Some door/window styles and furniture shapes are simplified. Material scale, roughness sliders and separate frame-material controls remain unfinished.
  • First-person mode uses lightweight camera navigation and has no collision constraints. Rugs deliberately bypass furniture collision checks.
  • Single-page PDF output; full Unicode font embedding and multi-page tiled printing are absent.
  • LocalStorage holds up to 20 projects. Browser privacy settings, clearing data and quotas can prevent persistence. JSON backups remain essential; concurrent editing of the same project in multiple tabs is not coordinated.
  • 60 rooms / 600 room vertices / 100 custom walls / 200 openings / 250 furniture items are capped. Large-plan rendering has not been profiled on low-end physical mobile devices.
  • Automated accessibility passed, but manual screen-reader coverage and real iOS/Android gesture testing remain outstanding. Firefox/Safari are unverified.
  • Mobile Lighthouse meets the requested 90+ score but LCP misses the 2.5-second target. No field Web Vitals or live hosting audit was available.

H. Deployment readiness

Production ready with documented limitations for conceptual, single-floor planning. Local checks and exports pass; incomplete advanced capabilities are disclosed.
